注意点

Opus 4.8 の fast mode が10/30付で廃止予定に、11/30に完全削除

Opus 4.8 の fast mode が deprecated になった。11月30日に削除され、以後は Opus 4.8 に対する fast mode リクエストはエラーを返すだけで、standard の Opus 4.8 への自動フォールバックは行われない。

つまりこう使う

  • /fast を Opus 4.8 で使っている場合は、11/30より前に Opus 5.5 に切り替えておく
  • CI やスクリプトで --fast や fast mode 指定のモデルを固定している箇所があれば、Opus 5.5 を指すように更新する
  • Claude Code changelog (v2.1.316)
新機能

Code Review 分析ページに「重大度別の指摘件数」カードを追加

Code Review の analytics ページに、期間ごとの指摘件数の合計・重大度で色分けした日次グラフ・各重大度の件数を表示するカードが追加された。

つまりこう使う

  • 組織の Code Review analytics ページを開き、重大度の高い指摘が増えていないか日次グラフで確認する運用に使える
  • Claude Code changelog (v2.1.316)
ワークフロー

クラウドセッションで、MCPサーバーからのフォーム入力依頼が見える形に

クラウドセッション中にMCPサーバーが追加入力（elicitation）を求めたとき、これまでは見えないまま黙ってキャンセルされていた。今回からフォームカードが表示され、入力して答えるか、明示的に断るかを選べるようになった。

つまりこう使う

  • クラウドセッションでMCPサーバーを使っていて途中で処理が止まった場合は、フォームカードが出ていないか確認する
  • 入力が不要なら「断る」を選べば、サーバー側に何も答えずに進められる
  • Claude Code changelog (v2.1.316)
Tips

`CLAUDE_CODE_SUBAGENT_EFFORT` でサブエージェントのeffortをまとめて指定

これまでサブエージェントは何も指定しなければメインセッションのeffort levelを継承していた。CLAUDE_CODE_SUBAGENT_EFFORT を設定すると、個々に effort を指定していないサブエージェントはこの値で動くようになる。

つまりこう使う

  • メインセッションは xhigh で動かしつつ、サブエージェントはコスト重視で medium に固定したい場合は CLAUDE_CODE_SUBAGENT_EFFORT=medium を設定する
  • Claude Code changelog (v2.1.316)
Tips

Ctrl+R の履歴検索が、折りたたまれた貼り付けテキストにもマッチするように

ターミナルで長いテキストを貼り付けると行が折りたたまれて表示されるが、これまで Ctrl+R の履歴検索はその中身を検索対象にしていなかった。今回から折りたたまれた貼り付けテキストの中身も検索にかかるようになった。

つまりこう使う

  • 以前貼り付けたログやコードの断片を覚えているなら、その文字列で Ctrl+R 検索すれば該当コマンドまで辿れる
  • Claude Code changelog (v2.1.314)
エコシステム

Claude Tag（SlackのClaude）、チャンネルの応答設定が「How Claude participates」に統合

Slack チャンネルの「Respond automatically」というオン・オフの設定が、チャンネルのConfigureページとClaude Tag管理設定の両方で「How Claude participates」という選択式の設定に変わった。

つまりこう使う

  • Claude Tag を導入しているSlackチャンネルがあれば、Configureページで「How Claude participates」の選択肢を確認し、意図した動作（常に応答する／メンション時のみ、など）になっているか見直す
  • Claude Code changelog (v2.1.316)

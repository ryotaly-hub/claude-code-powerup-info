新機能

`claude mcp add-json <name> -`で、MCPサーバーのJSON設定をstdinから渡せるように

v2.1.327で、claude mcp add-jsonにハイフン（-）を渡すと、サーバー設定のJSONを標準入力から読み込めるようになった。これまではJSONをコマンドライン引数に直接書く必要があり、APIキーなどのトークンがシェルの履歴やプロセス一覧に残ってしまう問題があった。なお、セッション内（対話中のClaude Codeから）では使えない。

つまりこう使う

  • echo '{"command":"npx","args":["-y","some-mcp-server"],"env":{"API_KEY":"..."}}' | claude mcp add-json myserver - のように、設定ファイルやパイプからJSONを渡して登録する。
  • 既存のスクリプトでトークンを引数に直書きしている箇所があれば、stdin経由に切り替えるとシェル履歴への露出を避けられる。
  • Claude Code Changelog (v2.1.327)
Tips

`/status`が、壊れたagent・skill・command・output styleファイルやフックの不備も一覧表示するように

v2.1.327で/statusの出力が拡充され、壊れているagent・skill・command・output styleファイル、キーバインドのエラー、使えなくなっているサンドボックス、無視されている権限設定、一度もマッチしないフックのmatcherまで一覧できるようになった。カスタム設定が増えてくると、どこが読み込めていないか気づきにくくなっていたための改善。

つまりこう使う

  • プラグインやカスタムagent・skillを多く入れている場合は、/statusを実行して「読み込めていない設定」や「マッチしないフック」が出ていないか一度確認する。
  • Claude Code Changelog (v2.1.327)
ワークフロー

`claude mcp add`/`remove`のproject scopeが、`.mcp.json`の他の設定を壊さなくなった

v2.1.327で、claude mcp add --scope project・claude mcp remove --scope projectが、.mcp.json内のmcpServers以外のトップレベルキーを誤って消していた不具合が修正された。さらに、.mcp.jsonがトップレベルに直接サーバーのリストを書く古い形式（mcpServersキーがない形式）になっている場合は、上書きせずに処理を停止するようになった。

つまりこう使う

  • チームで.mcp.jsonを共有している場合、claude mcp add/removeをproject scopeで実行してもファイル内の他設定が消えなくなったので、更新後にdiffで変更範囲を確認する運用を続けるとよい。
  • 古い形式の.mcp.jsonを使っている場合は、停止時のメッセージに従ってmcpServersキーを持つ形式に手動で直す。
  • Claude Code Changelog (v2.1.327)
注意点

Bashの初回コマンド実行が高速化。シェルの起動ファイルが承認前に走ることがある

v2.1.327で、最初のBashコマンド実行が速くなった。シェルの起動ファイル（.bashrcなど）が、ユーザーの承認が出るより前に実行され始めることがあるためで、承認前に副作用のあるコマンドが走る可能性がある。環境変数CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1を設定すると、この先行実行を無効化できる。

つまりこう使う

  • シェル起動ファイルに重い処理や副作用のあるコマンドを書いている場合は、承認前に実行されても問題ないか確認する。
  • 問題がある場合は環境変数CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1をセットして、この高速化を無効にする。
  • Claude Code Changelog (v2.1.327)
Tips

未知のモデルでの長い応答が、32,000トークンでなく128,000トークンまで継続されるように

v2.1.327で、認識されていないモデルIDで応答が長くなった場合の自動継続の上限が、32,000トークンから128,000トークンに上がった。これまでは32,000トークンに達した時点で応答が途中で止まってしまうことがあった。

つまりこう使う

  • カスタムモデルやプロバイダー経由でClaude Codeを使っていて長い出力が途中で切れていた場合、この変更により途中で止まりにくくなる。特別な設定変更は不要。
  • Claude Code Changelog (v2.1.327)
エコシステム

VS Code拡張のExplorer右クリックメニューに「Claude Code: Add to Chat」が追加

v2.1.327で、VS Code拡張のファイルエクスプローラーの右クリックメニューに「Claude Code: Add to Chat」が追加された。ファイルをドラッグ&ドロップしたりパスを手打ちしたりしなくても、右クリックから直接チャットにファイルを追加できる。

つまりこう使う

  • VS Codeのエクスプローラーでファイルやフォルダを右クリックし、「Claude Code: Add to Chat」を選ぶと、そのパスがチャット欄に追加される。
  • Claude Code Changelog (v2.1.327)

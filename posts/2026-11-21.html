新機能

自動でチャートを描く新モッド「easel」が追加。Pro・Max・（一部）Team・Enterprise、macOS/Linuxで利用可能

v2.1.330で、ビルトインのmod「easel」が追加された。チャートを頼んだときや、MCPツールがメトリクス結果を返したときに、自動でグラフを描く。現時点ではmacOS/Linuxで、Pro・Maxプラン、および一部のTeam・Enterpriseプランで利用できる。

つまりこう使う

  • 数値データをMCPツールから受け取ったときやチャートを頼んだときに、何もしなくても自動でグラフが表示されるようになる。
  • 自動描画が不要な場合は/configから easel の自動チャート機能をオフにできる。
  • Claude Code Changelog (v2.1.330)
注意点

`max_tokens`到達時の自動リトライ廃止が撤回され、v2.1.330で元の挙動に復活

v2.1.329で削除された「max_tokensエラーの上限に達したときに自動でリトライする」挙動が、v2.1.330で撤回され元どおり復活した。サードパーティゲートウェイ向けに使っていた環境変数CLAUDE_CODE_MAX_OUTPUT_TOKENS自体は引き続き使えるが、自動リトライが戻ったことで、必須だった設定が不要になるケースがある。

つまりこう使う

  • v2.1.329のタイミングでCLAUDE_CODE_MAX_OUTPUT_TOKENSを設定して回避策を入れていた場合、v2.1.330では自動リトライが復活しているので、設定を外しても問題ないか確認する。
  • 長い応答がmax_tokensエラーで止まる症状が再発していないか、v2.1.330にアップデート後に一度確認しておく。
  • Claude Code Changelog (v2.1.330)
ワークフロー

定期スケジュールタスクと`/loop`の継続期間が7日から30日に延長

v2.1.330で、セッションが起動し続けている限り、定期実行のスケジュールタスクと/loopは最長7日ではなく最長30日まで動くようになった。終了が近づくとその旨が表示される。なお、このリリースより前に作成済みのタスクは従来どおり7日で終了する。

つまりこう使う

  • 長期間回したい定期タスクや/loopは、v2.1.330以降で新しく作成すれば再スケジュールの手間が月1回程度に減る。
  • 既存の定期タスクを30日仕様にしたい場合は、一度停止して新規に作り直す必要がある。
  • Claude Code Changelog (v2.1.330)
注意点

root・home・トップレベル・作業フォルダそのものを狙う`rm`コマンドへの確認要求が拡大

v2.1.330で、ルートディレクトリやホームディレクトリ、トップレベルフォルダ、作業フォルダ自体を対象にしたrmコマンドについて、確認を求められる場面が増えた。確認に答えられない環境（無人実行など）では、該当コマンドは拒否されるようになっている。

つまりこう使う

  • CIやスケジュールタスクなど無人実行のスクリプトで大きめのrmを使っている場合、v2.1.330以降は拒否される可能性があるので、対象パスをより具体的に絞るか、事前に許可ルールを設定しておく。
  • Claude Code Changelog (v2.1.330)
新機能

VS Code拡張に`/fork`（会話をフォーク）と`/workflows`（実行中のワークフロー一覧）が追加

v2.1.330で、VS Code拡張に/forkコマンドが追加された。直前の返信のあとで会話をフォークできる。また/workflowsコマンドも追加され、実行中のワークフローを表示するagent mapを開ける。

つまりこう使う

  • VS Code拡張で今の会話から別の調査や実装を分岐させたいときは、/forkで直前の返信以降をフォークして並行して進められる。
  • 複数のワークフローを動かしているときは/workflowsで進行状況をまとめて確認する。
  • Claude Code Changelog (v2.1.330)
Tips

VS Code拡張に`claudeCode.escapeStopsClaude`・`claudeCode.pinPrompt`・`claudeCode.contextUsageThreshold`設定が追加

v2.1.330で、VS Code拡張の設定が3つ増えた。claudeCode.escapeStopsClaudeをオフにするとEscapeキーでClaudeを止めなくなる。claudeCode.pinPromptをオフにすると自分のメッセージを画面上部に固定せず、スクロールで流れるようにできる。claudeCode.contextUsageThresholdは、コンテキスト使用量インジケーターを表示し始めるしきい値を設定する。

つまりこう使う

  • 作業中にEscapeで誤ってClaudeを止めてしまう場合はclaudeCode.escapeStopsClaudeをオフにする。
  • 長い会話で自分のメッセージが常に上部に固定されるのが煩わしい場合はclaudeCode.pinPromptをオフにする。
  • コンテキスト使用量の表示をもっと早め（または遅め）に出したい場合はclaudeCode.contextUsageThresholdを調整する。
  • Claude Code Changelog (v2.1.330)

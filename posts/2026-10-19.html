注意点

コンテキストの小さいモデルへ切り替える際、要約生成の前に確認を求めるように（v2.1.301）

会話が新しいモデルのコンテキストウィンドウに収まらないとき、切り替え前の（元の）モデルが会話を要約してから切り替える。これまではその要約生成に使用量クレジットが無断で消費されていたが、今回の修正で切り替え前に確認が入るようになった。

つまりこう使う

  • 例えば 1M トークンのモデルから短いコンテキストのモデルへ /model で切り替えるとき、長い会話だと要約が走る場合がある。クレジットを使う操作として、切り替え前に確認ダイアログが出ることを覚えておく
  • Claude Code Changelog (GitHub)
ワークフロー

`claude agents`（agent view）で `/effort` と `/fast` を使って、新しいセッションの初期設定を指定できるように（v2.1.299）

agent view の画面から /effort でエフォートレベル、/fast で fast mode を指定すると、そこから新規に起動するセッションがその設定で始まる。

つまりこう使う

  • claude agents を開き、新しいセッションを作る前に /effort xhigh や /fast を打っておくと、起動するセッションに毎回設定し直す手間がなくなる
  • Claude Code Changelog (GitHub)
Tips

Read ツールに `allow_large` オプションが追加、通常の上限を超えるテキストファイルを一度に読めるように（v2.1.296）

Claude がファイル全体をどうしても必要とし、会話にそれを収める余地が残っている場合に向けたオプション。これを指定すると、通常のサイズ上限を超えるテキストファイルも1回の呼び出しで読み切れる。

つまりこう使う

  • SDK や自作ツールから Read を呼ぶ構成で、大きな設定ファイルやログを丸ごと読ませたい場合に allow_large: true を渡す。会話のコンテキストを大量に消費するので、本当に全体が必要なときだけ使う
  • Claude Code Changelog (GitHub)
Tips

VS Code 拡張、Claude の返答内の LaTeX 数式（`$$` や複数行の `\[ … \]`）がレンダリングされるように（v2.1.301）

これまで Claude の返答に含まれる数式はプレーンテキストのまま表示されていたが、VS Code 拡張のチャットパネルで数式として描画されるようになった。

つまりこう使う

  • 数式を含む説明や導出を Claude に書かせるとき、VS Code 拡張のチャット欄で確認すれば、$$...$$ や \[...\] がそのまま数式として読める
  • Claude Code Changelog (GitHub)
エコシステム

Claude Platform on AWS に `/advisor` が追加（v2.1.300）

/advisor、設定の advisorModel、または --advisor フラグでアドバイザーを選ぶまでは何も動かない。不要な場合は CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1 で機能自体を無効化できる。

つまりこう使う

  • Claude Platform on AWS を使っている場合、/advisor でアドバイザーを選んでから使い始める。使わない方針なら環境変数 CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1 を設定しておく
  • Claude Code Changelog (GitHub)

新機能

Claude Opus 5.5 が追加され、Opus のデフォルトモデルになった（v2.1.280）

Claude Opus 5.5（モデル ID: claude-opus-5-5）が追加された。1M トークンのコンテキストウィンドウを持ち、価格は入力 $4／出力 $20（per Mtok）、キャッシュ読み込みは $0.20／Mtok。Opus のデフォルトモデルに設定された。

あわせて、以前は起動時のエフォートレベルを引き継いでいた Opus 4.7・Opus 4.8・Fable 5 が、その扱いをやめた。エフォートレベルを固定で使っていた場合は挙動が変わる可能性がある。

つまりこう使う

  • /model で claude-opus-5-5 を選べる。既存プロジェクトで Opus を指定している場合は自動でこちらに切り替わる
  • Opus 4.7・4.8・Fable 5 でエフォートレベルを固定運用していたなら、/effort で現在の設定を確認し直す
  • Introducing Claude Opus 5.5（Anthropic）
  • Claude Code Changelog（公式）
注意点

Pro/Team Standard プランのデフォルトモデルが Sonnet から Opus に変わった（v2.1.280）

Pro および Team Standard プランで新しく始めるセッションのデフォルトモデルが、Sonnet から Opus に変更された。Opus は Sonnet よりコストが高いモデルなので、特に意識せず使い続けるとプラン上限への到達ペースが変わる。

つまりこう使う

  • プラン上限を意識する作業では /model で明示的に Sonnet を選ぶ
  • 切り替わり後の消費ペースが気になるなら /usage や /cost で確認する
  • Claude Code Changelog（公式）
注意点

シンボリックリンク越しの書き込みを acceptEdits・Auto mode が誤って許可できていたバグが直った（v2.1.280）

シンボリックリンク経由のパスへの書き込みが、リンク先ではなく見た目上のパス（in-tree の綴り）で権限判定されるバグがあった。プロンプトには書き込み先が正しく示されていたものの、acceptEdits モードや許可ルール、Auto mode の判定は別の実体パスに着地する書き込みも通してしまう可能性があった。v2.1.280 でこの判定が実際の着地先を見るように修正された。

つまりこう使う

  • シンボリックリンクを含むプロジェクトで acceptEdits や許可ルール、Auto mode を使っているなら v2.1.280 以降にアップデートする
  • claude update で更新し、/status でバージョンを確認する
  • Claude Code Changelog（公式）
Tips

`CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` で MCP ツール説明の文字数上限を変更できる（v2.1.280）

MCP サーバーのツール説明やサーバー指示（instructions）は、これまでセッションごとに 2,048 文字で切り詰められていた。新しい環境変数 CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH で、この上限をセッション内の全 MCP サーバーに対してまとめて変更できるようになった。

つまりこう使う

  • 説明文が長い MCP サーバーでツールの呼び出しが思わしくないなら、CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH=8192 claude のように起動時に上限を緩めて試す
  • 逆にコンテキストを節約したいなら、デフォルトの 2,048 より小さい値を設定する
  • Claude Code Changelog（公式）
エコシステム

Slack 版 Claude Tag に Working インジケーター・Stop ボタン・スレッドタイトルが追加された（v2.1.280）

Slack 上で動く Claude Tag のスレッドに、Slack 標準の「作業中」インジケーター、Stop ボタン、スレッドタイトルが表示されるようになった。これまで Claude の作業状況や中断操作は Claude Tag 独自の UI に頼っていたが、Slack ネイティブの見た目・操作に統合された。

つまりこう使う

  • Slack で Claude Tag に依頼したタスクを途中で止めたいときは、スレッド上の Stop ボタンをそのまま押す
  • 長いタスクを流しているスレッドは、追加されたスレッドタイトルで内容を見分けやすくなる
  • Claude Code Changelog（公式）

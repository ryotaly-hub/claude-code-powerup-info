POWERUP INFO / VOL.69
2026.11.27

11/25リリースのv2.1.332から、これまでの号で取り上げていなかった修正とワークフロー周りの変更を5本。認証・MCP・モデル指定に関わる地味だが実用的な内容が中心。

この号の内容

  1. `claude auth login`がログイン情報の保存に失敗したときも「成功」と表示していた不具合が修正
  2. Readツールが名前付きパイプ(named pipe)を読もうとしてハングする不具合が修正
  3. SSEのMCPサーバーが接続切断後にハングし続ける不具合が修正
  4. 他セッションからの保留メッセージに「Always deliver」オプションが追加
  5. `--model default`で指定モデルが使えない場合、エラーではなく利用可能な旧モデルへ自動フォールバックするように
注意点

`claude auth login`がログイン情報の保存に失敗したときも「成功」と表示していた不具合が修正

v2.1.332で、claude auth loginの不具合が修正された。これまでは認証情報の保存自体に失敗していても、コマンドは成功したかのように表示してしまっていた。保存に失敗した状態で使い続けると、次回起動時に再ログインを求められたり、セッションが突然切れたりする原因になっていた。

つまりこう使う

  • 最近claude auth login後に原因不明の再ログインや認証切れが起きていた場合、v2.1.332以降に更新すれば保存失敗が成功と誤表示されることはなくなる
  • 更新後も再ログインが頻発する場合は、保存先（Keychainなど）の権限自体を確認する
  • Claude Code changelog
注意点

Readツールが名前付きパイプ(named pipe)を読もうとしてハングする不具合が修正

v2.1.332で、Readツールが名前付きパイプ（FIFO）をファイルとして読み込もうとした際にハングしてしまう不具合が修正された。/dev/fd/*やプロセス間通信用のパイプをパスとして渡してしまうケースで発生していた。

つまりこう使う

  • スクリプトの出力をパイプ経由でClaude Codeに読ませるような構成を組んでいて以前フリーズしたことがある場合、v2.1.332以降なら解消されている
  • Claude Code changelog
注意点

SSEのMCPサーバーが接続切断後にハングし続ける不具合が修正

v2.1.332で、SSE（Server-Sent Events）方式のMCPサーバーが、ネットワークの切断などでストリームが途切れた後もハングし続ける不具合が修正された。それまではセッション側がタイムアウトせず、該当のMCPツールが使えない状態のまま固まってしまうことがあった。

つまりこう使う

  • SSE方式のリモートMCPサーバーを使っていて、接続が不安定な環境でセッションがハングした経験があるなら、v2.1.332への更新で改善が見込める
  • Claude Code changelog
ワークフロー

他セッションからの保留メッセージに「Always deliver」オプションが追加

v2.1.332で、別のClaude Codeセッションから届いた保留中のメッセージに「Always deliver」オプションが追加された。選ぶと、以後同じ送り主からのメッセージは確認なしで配信されるようになる。また、保留メッセージを送ってきたセッションが別モデルを使っている場合、/modelで選択するまでその旨がフッターに表示されるようになった。

つまりこう使う

  • 複数セッションをSendMessageやクロスセッションメッセージングで連携させている場合、信頼している送り主には保留メッセージ画面で「Always deliver」を選んでおくと、以後の確認が省ける
  • Claude Code changelog
Tips

`--model default`で指定モデルが使えない場合、エラーではなく利用可能な旧モデルへ自動フォールバックするように

v2.1.332で、--model defaultを指定したときの挙動が変わった。これまでは既定モデルが現在の環境で使えないとエラーで起動に失敗していたが、今後は利用可能な旧バージョンのモデルへ自動的にフォールバックして起動する。

つまりこう使う

  • Bedrock・Foundryなどデフォルトモデルの利用可否が環境によって異なる構成で--model defaultを使っている場合、起動時エラーで止まることが減る。実際にどのモデルで起動したかは/modelやセッション開始時の表示で確認する
  • Claude Code changelog

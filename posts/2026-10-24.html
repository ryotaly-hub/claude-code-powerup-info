新機能

Monitor ツールが Amazon Bedrock・Vertex AI・Foundry でも使えるように（v2.1.310）

Monitor ツールはバックグラウンドのイベントをストリーミングして会話に流し込み、ログを tail してリアルタイムに反応できるようにする機能。これまで Anthropic 直接プランでのみ使えたが、v2.1.310 で Amazon Bedrock・Google Cloud の Vertex AI・Microsoft Foundry 経由でも、Monitor ツールとプラグイン提供の monitor が使えるようになった。

あわせて、テレメトリ送信や非必須通信を無効化した環境でも、長時間のフォアグラウンド sleep はこれまで同様ブロックされるようになった。

つまりこう使う

  • Bedrock・Vertex AI・Foundry 経由で Claude Code を使っている場合も、CI の進捗やデプロイログを Monitor ツールで tail させ、完了や失敗を検知させられる
  • 長時間の待機は sleep を直接叩かず、Monitor ツールでイベントを待つ運用に寄せておく
  • Claude Code changelog (v2.1.310)
注意点

「Prompt is too long」後のコンパクションが密度の高いテキストを削り切れず、再度失敗する不具合を修正（v2.1.310）

会話が長くなりすぎて「Prompt is too long」エラーが出ると、自動でコンパクション（要約）が走る。しかし base64 データや巨大な SVG のような密度の高いテキストが会話に含まれていると、コンパクション後も十分に縮まらず、次のリクエストで同じエラーが再発することがあった。v2.1.310 でこの挙動が修正された。

つまりこう使う

  • 画像の base64 や大きな SVG をそのままプロンプトに貼り付けると、修正後もコンパクションの負荷が高い点は変わらないので、可能ならファイルパスで渡す運用にしておくとこのエラーに遭遇しにくい
  • Claude Code changelog (v2.1.310)
ワークフロー

`-p` など非対話セッションで、MCP ツールの応答待ちタイムアウトのエラーメッセージが改善（v2.1.310）

MCP サーバーがユーザー入力を求める elicitation を出したまま応答がなく、非対話セッション（-p や Agent SDK）でタイムアウトした場合、以前は原因がわかりにくいエラーになっていた。v2.1.310 では「応答が来なかったこと」と「同じ呼び出しを繰り返さないこと」を Claude 自身に伝えるようになり、同じツール呼び出しを延々と再試行してしまう事故を防ぎやすくなった。

つまりこう使う

  • -p や Agent SDK でユーザー入力待ちになる MCP ツールを使う構成の場合、非対話実行では応答できない前提で、該当ツールを外すか代替フローを用意しておく
  • Claude Code changelog (v2.1.310)
Tips

VS Code: プランレビューカードで Enter を押すと誤って計画を承認してしまう不具合を修正（v2.1.310）

VS Code 拡張のプランレビューカードで「Send feedback and keep planning」ボタンにフォーカスした状態で Enter を押すと、フィードバックを送るつもりが誤って計画そのものを承認してしまう不具合があった。v2.1.310 で修正され、Enter キーでこのボタンを押した場合は意図どおりフィードバックだけが送信されるようになった。

つまりこう使う

  • VS Code でプランモードを使い、修正コメントを送ってから計画を練り直したいときは、このボタンにフォーカスした状態で Enter を押すだけでよい（マウスクリックに持ち替える必要がない）
  • Claude Code changelog (v2.1.310)
Tips

VS Code 拡張の会話パネルで LaTeX の数式がレンダリングされるように（v2.1.301）

VS Code 拡張の会話パネルで、Claude の出力に含まれる LaTeX 形式の数式がそのままレンダリングして表示されるようになった。数式を多用するアルゴリズムの説明や論文実装のレビューが、別途 Markdown プレビューに貼り直さなくてもその場で読みやすくなる。

つまりこう使う

  • 数式を含む説明や証明をレビューしたいときは、VS Code 拡張の会話パネルでそのまま確認すればよい
  • Claude Code changelog (v2.1.301)
エコシステム

Enterprise のカスタムロールに「Cloud sessions」「Remote Control」の権限が追加（v2.1.310）

Enterprise プランの管理画面で、Owner がカスタムロールごとに Cloud sessions（クラウドセッション）と Remote Control の利用権限を個別に設定できるようになった。あわせて、管理設定でこの2つを有効化する操作には確認ダイアログが出て、その権限を持つカスタムロールの一覧が表示されるようになった。

つまりこう使う

  • Enterprise 管理者は、特定のロールだけにクラウドセッションや Remote Control の利用を許可する運用に切り替えられる
  • Claude Code changelog (v2.1.310)

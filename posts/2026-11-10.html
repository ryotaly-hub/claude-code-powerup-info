新機能

デフォルトのFableモデルがClaude Fable 5.2に切り替わり、コンテキストウィンドウは1Mトークンに

claude-fable-5-2が追加され、Fableモデルのデフォルトになった。コンテキストウィンドウは1Mトークン、価格は100万トークンあたり$8/$40（キャッシュ読み込みは$0.20/Mtok）。

保存済みのFable 5.1選択は自動的に新デフォルトのfableへ移行する。Pro・Maxプランでは即時、Team・Enterpriseプランでは組織側が5.2を許可した時点で移行する。

つまりこう使う

  • 特に何もしなくても、次回起動時からFableの既定は5.2になる
  • 5.1に戻したい場合は/model claude-fable-5-1を実行する
  • Team/Enterpriseで組織的に5.2への移行を止めたい場合は管理者側の許可設定を確認する
  • Claude Code changelog (v2.1.321)
ワークフロー

`claude remote-control --settings <file>`で、起動する全セッションに設定ファイルを適用できるように

claude remote-controlに--settings <file>オプションが追加された。指定したファイルの内容が、remote-control経由で起動する全セッションに適用される。ファイルを変更しても、remote-controlを再起動するまで新しいセッションは起動しない点に注意。

つまりこう使う

  • 複数の端末やメンバーからリモートで同じ設定（権限ルールやモデル指定など）を使わせたい場合、共通の設定ファイルを用意してclaude remote-control --settings team-settings.jsonのように起動する
  • 設定ファイルを更新したときは、反映させるためremote-control自体を再起動する
  • Claude Code changelog (v2.1.321)
注意点

Claude作成のmodが、auto/bypassモードでは確認なしに有効化されるように仕様変更

mod（Claudeが書いたインターフェース拡張）の有効化方法が変わった。Claudeが書いたmodは、auto modeやbypassモードでは確認を挟まずに有効化されるようになった。これは管理設定でallowUnsandboxedCommands: falseやallowManagedDomainsOnlyが設定されていても変わらない。一方dontAskモードではmod自体が読み込まれない。

またmod自身のツール呼び出し（$.tool.call・$.mcp.call）は、自分で設定したaskルールやdontAsk・-p実行下でも許可プロンプトを出さなくなった。ただしdenyルールと組織のポリシーはこれまでと同様に効く。

つまりこう使う

  • auto modeやbypassモードを使っている場合、今後はmodが確認なしで有効化・動作する前提で、入れているmodの内容を把握しておく
  • mod呼び出しを制限したい場合はaskルールではなくdenyルールで止める必要がある
  • Claude Code changelog (v2.1.321)
注意点

`/bin/cp`のようにパスを指定した`cp`・`mv`にも、通常の`cp`・`mv`と同じ権限チェックが適用されるように

cpやmvをフルパスで呼び出した場合（/bin/cpなど）、これまでコマンド名だけで判定していた権限チェックを素通りできる余地があったが、v2.1.321でパス指定時も通常のcp・mvと同じチェックが適用されるようになった。合わせて、ディレクトリへのcp・mvで実際に書き込まれるファイルに対しても、denyルールや保護ファイルの確認が正しく効くように修正されている。

つまりこう使う

  • cp・mvをdenyルールや保護ファイル設定で制限している場合、更新するだけでフルパス経由の回避ルートが塞がる。設定変更は不要
  • Claude Code changelog (v2.1.321)
Tips

fast modeが不調のときはまずモデルを切り替えずに通常速度で再試行、`/model`ピッカーの「More models」は最下行に、起動も高速化

fast modeがレート制限・過負荷・失敗している際、これまでは返信が失われたりモデルが切り替わったり、数分単位で再試行が続くことがあったが、まず同じモデルの通常速度での実行を試すようになった。

/modelピッカーでは「More models」が番号なしの行として一番下にまとめられ、古いモデルはそこに入る（他のモデルの番号はそのまま）。加えてclaude installとインストールスクリプトが2〜4秒ほど短縮され、信頼済みTLS証明書の読み込み高速化により起動も速くなった。

つまりこう使う

  • fast modeを使っていて応答が不安定だった場合、更新すればモデルが勝手に切り替わる前に同じモデルでの再試行を試してくれる
  • /modelで古いモデルを選びたいときは一覧の一番下の「More models」を開く

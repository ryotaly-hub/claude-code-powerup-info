注意点

Opus 4.8のfast modeは2026年11月30日に削除される

公式ドキュメントによると、Opus 4.8のfast modeは2026年10月30日付けで非推奨となっており、2026年11月30日に削除される。削除後もOpus 4.8でfast modeをオンにしたままだと、APIがリクエストを拒否するようになる。

速度を維持したい場合はOpus 5.5へ切り替えるのが案内されている。Opus 4.8を標準速度のまま使い続けるだけなら/fast offでよい。

つまりこう使う

  • Opus 4.8でfast modeをオンにして使っている場合、11/30までに/modelでOpus 5.5に切り替えるか、/fast offでfast modeを切っておく
  • Opus 5.5への切り替えにはClaude Code v2.1.280以降が必要
  • Speed up responses with fast mode
新機能

MCPサーバー提供のSkillが使えるようになった（beta）

v2.1.332で、MCPサーバーが提供するSkillを使えるようになった（beta）。こうしたSkillは/メニューにserver:skillの形式で表示され、通常のSkillは今までどおりの名前のまま表示される。

つまりこう使う

  • MCPサーバーがSkillを提供している場合、/メニューにサーバー名:スキル名の形式で現れるので、通常のSkillと見分けて呼び出せる
  • Claude Code changelog
ワークフロー

新しいフックイベント`PreSkillShellCommand`が追加

Skillやコマンドのロード時にインラインのシェルコマンドが実行される場面で、それを拒否できるフックイベントPreSkillShellCommandがv2.1.332で追加された。v2.1.331以前では、設定ファイルでこのイベント名を指定すると起動時にダイアログが出てしまっていた。

つまりこう使う

  • SkillやコマンドのインラインシェルコマンドをCIなどで制限したい場合、PreSkillShellCommandフックを設定して拒否条件を書く
  • v2.1.332より前のバージョンで同名のフックを設定ファイルに書いていた場合は、起動時にダイアログが出ていた不具合なので更新してから使う
  • Claude Code changelog
Tips

`/permissions`が、起動時に無視されるルールの追加を拒否するように改善

/permissionsで、起動時に実際には適用されないルールを登録しようとすると拒否され、理由が表示されるようになった。例えばツール名を指定しないrm -rfのような書き方が対象になる。

つまりこう使う

  • パーミッションルールを追加しようとして/permissionsに拒否された場合、ツール名の指定漏れなど、起動時に無視される書き方になっていないか見直す
  • Claude Code changelog
注意点

computer useが有効なMacでは、`computer-use`という名前のSkill・コマンドが予約語になった

Macでcomputer useが有効な場合、computer-useという名前は予約済みとなり、同名の自作Skillやコマンドは読み込まれなくなった。該当する場合は起動時にリネームを促す通知が表示される。

つまりこう使う

  • Macでcomputer useを使っていて、computer-useという名前のSkillやコマンドを自作している場合、起動時の通知に従って別名にリネームする
  • Claude Code changelog
ワークフロー

VS Codeで、`/rewind`による会話復元が実行中のself-paced `/loop`を止める場合に警告が表示されるように

VS Code拡張のサイドバーから/rewindで会話を復元する操作が、間隔指定なし（self-paced）で動かしている/loopを停止させてしまう場合に、その旨の警告が追加された。

つまりこう使う

  • VS Codeで間隔指定なしの/loopを動かしている最中に/rewindで会話を戻す場合は、loopが止まる可能性があるという警告を確認してから進める
  • Claude Code changelog

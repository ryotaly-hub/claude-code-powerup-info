新機能

Claude Sonnet 5.5（`claude-sonnet-5-5`）が Anthropic API のデフォルト Sonnet モデルに（v2.1.284）

v2.1.284 で、Anthropic API 上のデフォルト Sonnet モデルが claude-sonnet-5-5 に切り替わった。1M トークンのコンテキストウィンドウを持ち、価格は 1 Mtok あたり入力 $2 / 出力 $10、キャッシュ読み取りは $0.20 / Mtok。

Claude Code は内部でこの Anthropic API を呼び出しているため、モデル指定を固定していない環境では、次回起動時から Sonnet 系呼び出しの実体がこのモデルに切り替わることになる。

つまりこう使う

  • /status を開き、使用中の Sonnet モデルが claude-sonnet-5-5 になっているか確認する
  • コンテキスト長やキャッシュ戦略に依存した運用をしているチームは、新しい価格（$2/$10、キャッシュ読み取り $0.20）でコスト試算をやり直しておく
  • Claude Code Changelog（公式）
ワークフロー

auto mode の作業ディレクトリ外読み取り確認に「今回だけ許可、次はまた聞く」が追加（v2.1.284）

auto mode で作業ディレクトリの外にあるファイルを読もうとすると確認プロンプトが出るが、これまでは許可すると以降も許可されたままになるか、毎回聞かれるかの二択だった。v2.1.284 で「Yes, but ask again next time」という選択肢が加わり、今回の読み取りだけを許可しつつ、次に別のファイルを読もうとしたときは改めて確認させることができるようになった。

つまりこう使う

  • auto mode で作業ディレクトリ外のファイル読み取りを確認されたとき、恒久的に許可したくない場合は「Yes, but ask again next time」を選ぶ
  • 一時的な調査で外部ファイルを何度も参照する場合でも、都度確認が入るので意図せず広い許可を出さずに済む
  • Claude Code Changelog（公式）
Tips

`/mcp reconnect all` で接続失敗・要認証の MCP サーバーを一括再接続（v2.1.284）

対話型ターミナルで /mcp reconnect all を実行すると、接続に失敗している、または認証が必要になっている MCP サーバーをまとめて再接続できるようになった。これまでは /mcp メニューからサーバーごとに個別に再接続する必要があった。

つまりこう使う

  • 複数の MCP サーバーを使っていて、セッション開始時にいくつか接続エラーが出ているときは /mcp reconnect all を実行する
  • 特定のサーバーだけ再接続したい場合は、従来どおり /mcp メニューから個別に操作する
  • Claude Code Changelog（公式）
Tips

`/effort` スライダーのキー操作を `keybindings.json` で再割り当て可能に（v2.1.284）

/effort スライダーを操作する矢印キーと Tab キーの挙動が、effortSlider:decreaseEffort / effortSlider:increaseEffort / toggleUltracode という3つのキーバインドアクションに分離され、keybindings.json から再割り当てできるようになった。

つまりこう使う

  • 矢印キーや Tab キーが他のショートカットと衝突している場合、keybindings.json で effortSlider:decreaseEffort などに別のキーを割り当てる
  • Ultracode の切り替えだけ別キーにしたい場合は toggleUltracode を個別に設定する
  • Claude Code Changelog（公式）
エコシステム

Claude apps gateway の spend limit、`/usage` とステータスラインに実際の金額で表示（v2.1.284）

組織の Claude apps gateway 経由で利用している場合、これまで /usage やステータスラインの支出上限表示は間接的な表示だったが、v2.1.284 以降のゲートウェイでは「$271.40 / $500.00 spent this month」のように実際の金額で表示されるようになった。ステータスライン向けの rate_limits.spend_limit にも used_usd / limit_usd / period が加わっている。

つまりこう使う

  • 組織で Claude apps gateway を運用している場合は、ゲートウェイ自体を v2.1.284 以降に更新して金額表示を有効にする
  • ステータスラインを自作している場合は rate_limits.spend_limit.used_usd / limit_usd / period を読んで表示に組み込める
  • Claude Code Changelog（公式）

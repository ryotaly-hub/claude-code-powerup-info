新機能

`/auto-mode-setup` で auto mode を自分の環境向けにガイド設定

v2.1.304 で /auto-mode-setup が追加された。プロジェクトと直近のセッションを読み取り、auto mode にその環境のクセを学習させるガイド付きセットアップで、Amazon Bedrock・Google Vertex AI・Microsoft Foundry・Claude apps gateway・テレメトリ無効のセッションでも使えるようになった。

auto mode は許可プロンプトの代わりにバックグラウンドの安全チェックで判断するモードなので、環境に合わせてチューニングしておくほど誤検知が減る。

つまりこう使う

  • auto mode を使っているプロジェクトで /auto-mode-setup を一度実行し、許可ルールと安全チェックの調整を任せる。
  • claude-code v2.1.304 release notes
ワークフロー

`claude -p` / Agent SDK、巨大なトランスクリプトのコンパクション時メモリ使用量を改善

v2.1.310 で、claude -p や Agent SDK を使う非対話セッションがコンパクションを行う際、トランスクリプトファイルが非常に大きい場合のメモリ使用量が改善された。

つまりこう使う

  • CI や自動化スクリプトで claude -p を長時間・大きな入力で回している場合、アップグレードするだけで OOM で落ちにくくなる。
  • claude-code v2.1.310 release notes
Tips

Linux サンドボックス: AppArmor 起因の起動失敗にメッセージが付き、`allowNestedUserNamespaces` で user namespace を許可できる

v2.1.310 で、Ubuntu の AppArmor が user namespace の作成を制限していて bubblewrap がサンドボックスを起動できないとき、/sandbox とサンドボックス起動時の警告がその原因と解除方法を名指しするようになった。

また v2.1.305 では sandbox.allowNestedUserNamespaces 設定が追加され、Chromium や rootless podman のようにサンドボックス内で user namespace を作る必要があるコマンドを許可できる。ただしこれはサンドボックスのファイル保護を一部迂回することになるので、必要な場合だけ有効にする。

つまりこう使う

  • Ubuntu でサンドボックスが起動しない場合は /sandbox のエラーメッセージに従って AppArmor の制限を確認する。
  • サンドボックス内で Chromium や rootless podman を動かす必要があるなら、settings.json に "sandbox": { "allowNestedUserNamespaces": true } を追加する。
  • claude-code v2.1.310 release notes
  • claude-code v2.1.305 release notes
Tips

クラウドセッション内の `claude -p` が誤って「ログインしていません」と表示する不具合を修正

v2.1.306 で、クラウドセッションの中からセッションの環境変数を渡さずに claude -p を起動すると「Not logged in」と誤表示される不具合が修正された。

つまりこう使う

  • クラウドセッションから入れ子で claude -p を呼ぶ自動化を組んでいる場合は、アップグレードすれば認証エラーで止まらなくなる。
  • claude-code v2.1.306 release notes
注意点

ファイル読み取りの許可プロンプトが、シンボリックリンクの先を表示するように

v2.1.310 で、ファイル読み取りの許可を求めるプロンプトが、対象がシンボリックリンクの場合にそのリンク先を表示していなかった不具合が修正された。許可を出す前にリンク先を確認できる。

つまりこう使う

  • 許可プロンプトでパスがシンボリックリンクだと分かったら、リンク先が意図した場所を指しているか確認してから許可する。
  • claude-code v2.1.310 release notes
注意点

`cleanupPeriodDays` を大きくしていると、直近に貼り付けた画像などが誤って削除される不具合を修正

v2.1.310 で、cleanupPeriodDays を非常に大きい値に設定していると、バックグラウンドのクリーンアップが貼り付けた画像のような直近のファイルまで削除してしまう不具合が修正された。

つまりこう使う

  • この設定をデフォルトより大きくして使っている場合は、アップグレードしておく。
  • claude-code v2.1.310 release notes

POWERUP INFO / VOL.64
2026.11.22

Claude Codeの公式changelog(v2.1.327〜330)から、これまでの号で取り上げていない項目をまとめた。worktreeの誤削除やMCPサーバーの接続拒否、設定の隠れた通知など、気づきにくいが知っておくと事故を防げる変更が中心。

この号の内容

  1. 信頼ダイアログが、未信頼フォルダのフックがどこで宣言されているかを警告するように
  2. `/mcp`に、リモートMCPサーバーが接続を拒否したときの「Server message」が表示されるように
  3. `/install-github-app`がリポジトリを変更する前に、確認を求めるようになった
  4. `ExitWorktree`が、未保存の作業が残っているworktreeを削除する前に確認するように
  5. `Ctrl+O`で、起動時に隠れた通知を表示できる
  6. `deniedMcpServers`の名前指定は、該当コネクタ1件だけを隠す仕様に変更
Tips

信頼ダイアログが、未信頼フォルダのフックがどこで宣言されているかを警告するように

未信頼のフォルダを開いたとき表示される信頼確認ダイアログに、そのフォルダにhooksが設定されている場合はその宣言場所（プロジェクト設定か管理設定かなど）を示す警告が追加された。

つまりこう使う

  • 知らないリポジトリを開いて信頼確認が出たとき、hooksの警告が出たら内容を.claude/settings.jsonなどで確認してから信頼する
  • Claude Code Changelog (v2.1.329)
Tips

`/mcp`に、リモートMCPサーバーが接続を拒否したときの「Server message」が表示されるように

リモートHTTPのMCPサーバーが接続を拒否した場合、/mcpの表示にサーバー側が返したメッセージが「Server message」として出るようになった。認証エラーなど拒否理由がそのまま見える。

つまりこう使う

  • リモートMCPサーバーに接続できないときは、まず/mcpを開いてServer messageを確認する。認証トークンの期限切れなど原因が特定しやすい
  • Claude Code Changelog (v2.1.329)
注意点

`/install-github-app`がリポジトリを変更する前に、確認を求めるようになった

/install-github-app実行時、GitHub Appのインストールやリポジトリ設定の変更を加える直前に確認プロンプトが入るようになった。それまでは確認なしで変更されていた。

つまりこう使う

  • CI連携などのためにGitHub Appを導入するときは、確認内容を読んでから進める
  • Claude Code Changelog (v2.1.327)
ワークフロー

`ExitWorktree`が、未保存の作業が残っているworktreeを削除する前に確認するように

worktreeを終了・削除するExitWorktreeが、コミットされていない変更が残っている可能性があるworktreeに対しては、削除前に確認を求めるようになった。

つまりこう使う

  • 複数worktreeを並行して使っているとき、確認が出たらコミットかstashを済ませてから削除する
  • Claude Code Changelog (v2.1.327)
Tips

`Ctrl+O`で、起動時に隠れた通知を表示できる

起動時に表示される通知のうち、画面に出てこなかったものをCtrl+Oで後から確認できるようになった。

つまりこう使う

  • 起動直後に何か表示が流れた気がしたらCtrl+Oを押す
  • 権限モードの自動選択や設定の読み込みエラーなど、気づきにくい通知を見逃さずに済む
  • Claude Code Changelog (v2.1.326)
注意点

`deniedMcpServers`の名前指定は、該当コネクタ1件だけを隠す仕様に変更

設定deniedMcpServersにclaude.ai <名前>のようにコネクタ名で指定した場合、そのコネクタだけが隠れるようになった。同じURLの他のコネクタまでまとめて隠したい場合は、名前の代わりに正確なURLを指定して拒否する必要がある。

つまりこう使う

  • deniedMcpServersでコネクタをブロックする設定をしている場合、名前指定では漏れがあるかもしれないので、URL単位で止めたいものはURLで指定し直す
  • Claude Code Changelog (v2.1.330)

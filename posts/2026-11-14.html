POWERUP INFO / VOL.56
2026.11.14

v2.1.323（11/12）とv2.1.325（11/13）の変更から、自動化やスキル運用に直結するものを中心に6本選んだ。サンドボックス化Bashコマンドとスケジュールタスク/`/loop`の権限確認の変更は、無人実行の設定を見直す必要があるため最初に扱う。

この号の内容

  1. サンドボックス化されたBashコマンドが、デフォルトで通常の権限フローに従うようになった
  2. スケジュールタスクや`/loop`が、`allowed-tools`やhooksを宣言するスキルの実行前に確認を求めるようになった
  3. 実験的な「Code Mode」。ClaudeがJavaScriptのコードを書いてツールを呼び出すようになる
  4. 同じマシン上のセッション間メッセージングの上限が、20通から100,000通に拡大
  5. VS Code統合ターミナルに次のプロンプト候補が表示されるようになり、`Tab`で受け入れられる
  6. `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES=1`で、サブエージェントの進捗要約とそのためのリクエストを止められる
注意点

サンドボックス化されたBashコマンドが、デフォルトで通常の権限フローに従うようになった

v2.1.325の変更。これまでサンドボックス内で実行されるBashコマンドは確認なしで動いていたが、デフォルトでは他のツール呼び出しと同じ通常の権限フロー（許可プロンプト）に従うようになった。以前の「確認なしで実行」という挙動を維持したい場合は、設定で明示的にオプトインする必要がある。

つまりこう使う

  • 設定ファイルに"sandbox": { "autoAllowBashIfSandboxed": true }を追加すると、サンドボックス化されたBashコマンドを確認なしで実行する以前の挙動に戻せる。
  • サンドボックスを多用する自動化・CIでは、この設定を入れていないと確認プロンプトで止まるようになる点に注意。
  • Claude Code Changelog
注意点

スケジュールタスクや`/loop`が、`allowed-tools`やhooksを宣言するスキルの実行前に確認を求めるようになった

v2.1.325の変更。スケジュールされたタスクや/loopが、allowed-toolsやhooksを宣言しているスキルを実行する前に、確認を求めるようになった。無人で実行させたい場合は、そのスキルを明示的に許可リストに加える必要がある。

つまりこう使う

  • 無人実行させたいスキルがある場合、設定のpermissions.allowにSkill(<スキル名>)を追加しておく。
  • 日次で自動実行しているルーティンやcronタスクが、allowed-toolsやhooksを持つスキルを呼んでいる場合は、この変更後に確認待ちで止まっていないか確認する。
  • Claude Code Changelog
新機能

実験的な「Code Mode」。ClaudeがJavaScriptのコードを書いてツールを呼び出すようになる

v2.1.323で追加された、オプトインの実験的機能。有効にすると、Claudeは個々のツール呼び出しを1つずつ出す代わりに、JavaScriptコードを書いてまとめてツールを呼び出すようになる。

つまりこう使う

  • オン/オフの手順はドキュメントで確認する。組織単位でオフにすることもできる。
  • まだ実験的機能なので、本番のワークフローに組み込む前に手元のタスクで挙動を確かめておくとよい。
  • Claude Code Changelog
  • Code Mode
ワークフロー

同じマシン上のセッション間メッセージングの上限が、20通から100,000通に拡大

v2.1.323の変更。同じマシン上で動くClaude Codeセッション同士が、確認なしで送り合えるメッセージ数の上限が、約20通から100,000通に大きく拡大された。

つまりこう使う

  • 複数セッションをまたいで検出結果や指示を頻繁にやり取りするワークフロー・エージェント間連携でも、確認プロンプトで止められにくくなる。
  • Claude Code Changelog
Tips

VS Code統合ターミナルに次のプロンプト候補が表示されるようになり、`Tab`で受け入れられる

v2.1.325の変更。VS Code拡張で、ターミナルが次のプロンプト候補を表示できる場所ならどこでも提案が出るようになった。Tabキーで提案を受け入れられる。

つまりこう使う

  • 不要な場合は、settings.jsonの"promptSuggestionEnabled": falseで無効化できる。
  • Claude Code Changelog
Tips

`CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES=1`で、サブエージェントの進捗要約とそのためのリクエストを止められる

v2.1.318から使える環境変数だが、v2.1.323のchangelogで改めて記載された。CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIESを1に設定すると、サブエージェントの進捗要約の表示と、それを生成するためのリクエスト自体を止められる。

つまりこう使う

  • サブエージェントを多数走らせるワークフローでトークン消費や表示のノイズを減らしたい場合、この環境変数を1に設定する。
  • Claude Code Changelog

前号：v2.1.319の見落とし分。MCPのツール呼び出しがタスク化され自動でバックグラウンド実行に、`permissions.denyInsteadOfPrompting`で許可待ちせず拒否して続行できるように。`/tasks`に終了済みサブエージェントへ後からメッセージできる行が追加。`/loop`のセルフペースはターン終了で自動停止するよう仕様変更、継続には`CLAUDE_CODE_LOOP_KEEPALIVE=1`が必要

POWERUP INFO / VOL.65
2026.11.23

11/18〜22号で取り上げてきたv2.1.326〜330には、まだ拾っていない変更が残っている。モデル指定とgit操作周りを中心に、知らないと挙動の変化に戸惑いそうな6本をまとめた。

この号の内容

  1. `claude --teleport`が一部の環境では、gitコマンドを実行せず表示するだけになった
  2. Skillの`model`設定が、以後のサブエージェント・フォーク・compaction・`/recap`にも引き継がれる
  3. Prompt hooksの`model`欄に`haiku`・`sonnet`などのエイリアスが使えるように
  4. 認識できないモデル名に`sonnet`・`haiku`が含まれると、短縮版のシステムプロンプトが使われる
  5. VS Code拡張の「Open in Side Bar」に`prompt`引数、セッショングループに並び替えが追加
  6. `CLAUDE_CODE_FULL_SIGN_IN_LINK=1`で、省略されないサインインリンクを表示できる
注意点

`claude --teleport`が一部の環境では、gitコマンドを実行せず表示するだけになった

worktreeなどブランチを切り替える--teleportは、セットアップによっては実際にgitコマンドを実行せず、実行すべきコマンドを表示するだけの動作に変わった。-p（非対話）モードで使っている場合、ユーザーが実際にブランチを切り替えるまで終了コードが1を返す。

つまりこう使う

  • --teleportを使った自動化スクリプトがあるなら、ブランチ切り替えが自動で完了しない前提に直し、表示されたgitコマンドを手動で実行する手順を挟む
  • CIなど-pで使っている場合は終了コード1をハンドリングするようにする
  • Claude Code Changelog (v2.1.330)
ワークフロー

Skillの`model`設定が、以後のサブエージェント・フォーク・compaction・`/recap`にも引き継がれる

frontmatterでmodelを指定したSkillを実行すると、そのモデルがそのセッションの以後の処理（サブエージェント起動、フォーク、要約=compaction、/recap）でも維持されるようになった。context: forkのSkillはこの挙動の対象外。

つまりこう使う

  • 特定のSkillだけ軽いモデル（例: haiku）で動かすつもりでfrontmatterにmodel: haikuと書いた場合、以後の処理も含めてそのモデルのまま動くことを想定しておく
  • フォーク先だけ別モデルにしたいなら、そのSkillはcontext: forkにする
  • Claude Code Changelog (v2.1.330)
Tips

Prompt hooksの`model`欄に`haiku`・`sonnet`などのエイリアスが使えるように

フック設定でモデルを指定するとき、claude-haiku-4-5のようなフルのモデルIDを書かなくても、haikuやsonnetといった短いエイリアスで指定できるようになった。

つまりこう使う

  • 既存のprompt hooksのmodel欄がフルIDで書かれているなら、haikuやsonnetに書き換えて短くできる
  • Claude Code Changelog (v2.1.330)
注意点

認識できないモデル名に`sonnet`・`haiku`が含まれると、短縮版のシステムプロンプトが使われる

サードパーティのプロキシやカスタムエンドポイント経由などでClaude Codeが認識しないモデル名を使う場合、その名前にsonnetまたはhaikuという文字列が含まれていると、短い系統のシステムプロンプトが使われるようになった。

つまりこう使う

  • カスタムのモデル名・エイリアスにsonnet/haikuという文字列が入っていると挙動が変わりうることを把握しておく
  • フルのシステムプロンプトを使わせたい場合はCLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0を設定する
  • Claude Code Changelog (v2.1.330)
Tips

VS Code拡張の「Open in Side Bar」に`prompt`引数、セッショングループに並び替えが追加

VS Code拡張で、セッションをサイドバーで開く「Open in Side Bar」操作に最初のプロンプトを渡すprompt引数が加わった。また、セッショングループのメニューからMove up / Move downで並び順を変更できるようになった。

つまりこう使う

  • サイドバーで新規セッションを開くときに最初のプロンプトまで一緒に渡せるようになったので、よく使う指示はコマンド登録しておくと呼び出しが速くなる
  • 複数セッションをグループ化して使っているなら、Move up / Move downで並び順を整理する
  • Claude Code Changelog (v2.1.330)
Tips

`CLAUDE_CODE_FULL_SIGN_IN_LINK=1`で、省略されないサインインリンクを表示できる

ターミナルに表示されるサインインリンクは短縮表示になることがあるが、この環境変数を立てて起動すると、省略されない完全なリンクがそのまま出力される。

つまりこう使う

  • SSH先やログ経由でリンクをコピーする必要があるときはCLAUDE_CODE_FULL_SIGN_IN_LINK=1 claudeで起動する
  • Claude Code Changelog (v2.1.330)

POWERUP INFO / VOL.61
2026.11.19

11月16日・17日リリースのv2.1.326・v2.1.327から、これまでの号で触れていなかった項目を拾った。権限確認とサンドボックスが厳しくなる方向の変更が続くので、autoモードやPowerShellを使っている場合は特に確認しておきたい。

この号の内容

  1. WebFetchが2,000文字を超えるURLを、権限確認プロンプトより前に拒否するように
  2. autoモードのフォールバック分類器リクエストは、将来のリリースで廃止予定
  3. PowerShellツールは、ルールで許可済みのコマンドでも確認を求める場面が増えた
  4. Claude in Chromeが一部の資格情報ファイルのアップロードを拒否するように
  5. `/tui classic`が、従来の非フルスクリーン描画モードの正式名称になった
  6. VPN切断などで切れたリモートMCPサーバーへの接続が、約1日間バックグラウンドで再接続を試みるように
注意点

WebFetchが2,000文字を超えるURLを、権限確認プロンプトより前に拒否するように

v2.1.327で、WebFetchツールに渡したURLが2,000文字を超えている場合、権限の確認プロンプトを出す前に拒否されるようになった。クエリパラメータが長いドキュメントページや検索結果URLをそのまま渡すと、確認する間もなく失敗する。

つまりこう使う

  • WebFetchがURLを渡した直後に失敗する場合は、まずURLの長さを数える。
  • 長いURLはクエリパラメータを削るか、短縮・正規化したURLに置き換えてから渡す。
  • Claude Code Changelog (v2.1.327)
注意点

autoモードのフォールバック分類器リクエストは、将来のリリースで廃止予定

v2.1.326で、autoモードが権限チェックをローカル分類器ではなくAPI経由の課金対象リクエストにフォールバックした際の通知文が変更され、今後のリリースでこのフォールバック自体を廃止すると明記された。廃止後は、これまでフォールバックで処理されていたアクションは、確認を求められるか拒否されるようになる。

つまりこう使う

  • autoモードを使っている場合、今の時点でフォールバック通知が頻発していないか/statusなどで確認しておく。
  • 将来のアップデートで確認や拒否が増える可能性を想定し、よく使う操作は事前にallowルールを整理しておくとよい。
  • Claude Code Changelog (v2.1.326)
ワークフロー

PowerShellツールは、ルールで許可済みのコマンドでも確認を求める場面が増えた

v2.1.327で、PowerShellツールは個々のコマンドを許可するルールがあっても、追加でもう一度確認を求める場面が増えるよう変更された。確認に誰も応答しない場合、ツール全体を許可するルール・autoモード・bypass permissionsモードのいずれかがない限り、そのコマンドは拒否される。

つまりこう使う

  • Windows上でPowerShellコマンドを多用するワークフローでは、確認が増えることを前提に進める。
  • 確認を省きたい場合は、個別コマンドのルールではなくPowerShellツール全体を許可するルールか、autoモードの利用を検討する。
  • Claude Code Changelog (v2.1.327)
エコシステム

Claude in Chromeが一部の資格情報ファイルのアップロードを拒否するように

v2.1.327で、ブラウザ拡張のClaude in Chromeは、認証情報を含むとみなされる一部のファイルをWebページにアップロードすることを拒否するよう変更された。そうしたファイルをサイトに渡す必要がある場合は、ユーザー自身の操作で添付する。

つまりこう使う

  • Claude in Chromeでファイルアップロードが拒否されたら、アップロード対象が資格情報ファイルに該当していないか確認する。
  • 業務上どうしても必要な場合は、該当ファイルを自分の手で選択してアップロードする。
  • Claude Code Changelog (v2.1.327)
新機能

`/tui classic`が、従来の非フルスクリーン描画モードの正式名称になった

v2.1.327で、これまで名前のなかった従来の非フルスクリーン描画モードが/tui classicと呼べるようになった。フルスクリーン描画を指す/tui defaultは引き続き使える。

つまりこう使う

  • フルスクリーン描画で画面の乱れや表示崩れが出る場合、/tui classicを実行して従来の描画モードに切り替える。
  • 元のモードに戻すには/tui defaultを実行する。
  • Claude Code Changelog (v2.1.327)
Tips

VPN切断などで切れたリモートMCPサーバーへの接続が、約1日間バックグラウンドで再接続を試みるように

v2.1.326で、VPNの切断など長時間の障害でリモートMCPサーバーへの接続が切れたままになる不具合が修正された。ホスト名でhttps経由で到達するほとんどのリモートMCPサーバーは、接続が切れても約1日間はバックグラウンドで再接続が試行され続ける。

つまりこう使う

  • VPNが一時的に切れてMCPサーバーが使えなくなっても、すぐにclaude mcp remove/addし直さず、少し待ってから/mcpで接続状態を確認する。
  • 1日以上経っても再接続されない場合は、サーバー側の設定や認証情報を見直す。
  • Claude Code Changelog (v2.1.326)

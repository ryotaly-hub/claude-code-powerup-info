新機能

クラウドセッションに GitHub CLI 不要で使える組み込みの `gh api` が追加（v2.1.288）

クラウド上の Claude Code セッションで、gh CLI をインストールしなくても gh api が組み込みで使えるようになった。これまでセルフホスト環境以外のクラウドセッションでは GitHub API を直接叩く手段がなく、個別にセットアップが必要だった。

つまりこう使う

  • クラウドセッション内で gh api repos/<owner>/<repo>/pulls/123 のように、インストール手順なしでそのまま叩ける
  • gh pr view などのサブコマンドより、まずは gh api 経由での直接呼び出しを想定した機能
  • Claude Code Changelog
ワークフロー

`claude agents` 画面の検索に Ctrl+F、グループ間の移動に Alt+↑/↓ が追加（v2.1.288）

エージェントビュー（claude agents）に、セッションを名前で絞り込む Ctrl+F と、グループ（実行中・完了などの分類）間をジャンプする Alt+↑/↓ が追加された。多数のセッションを並行して走らせているときに、目的のセッションを探す手間が減る。

つまりこう使う

  • claude agents を開いた状態で Ctrl+F を押し、セッション名で絞り込む
  • Alt+↑ / Alt+↓ でグループ単位にジャンプし、カーソル移動の回数を減らす
  • Claude Code Changelog
Tips

`/code-review` に `--max-findings <n>|all` が追加、レポートする finding 数を指定できる（v2.1.288）

/code-review コマンドに --max-findings オプションが追加され、レポートに出す finding の件数を自分で決められるようになった。<n> で件数を絞る、all で全件出す、の切り替えができる。一度指定した件数はその後の実行にも引き継がれ、--max-findings default で元の挙動に戻せる。

つまりこう使う

  • /code-review --max-findings 3 のように件数を指定すると、以降の実行もその件数でレポートされる
  • 全件確認したいときは /code-review --max-findings all、元に戻すときは /code-review --max-findings default を使う
  • Claude Code Changelog
Tips

Ctrl+C でクリアしたプロンプトを ↑ キーで復元できるように（v2.1.288）

入力中のプロンプトを Ctrl+C でクリアしてしまっても、直後に ↑ キーを押すと消した内容がドラフトとして戻ってくるようになった。長文を書いている途中に誤って Ctrl+C を押してしまうケースの救済策。

つまりこう使う

  • Ctrl+C でプロンプトを消してしまったら、すぐに ↑ キーを押して直前のドラフトを呼び戻す
  • Claude Code Changelog
エコシステム

MCP サーバーが追加の OAuth スコープを要求したとき、再認証プロンプトが出るように（v2.1.288）

接続済みの MCP サーバーが後から追加の OAuth スコープを要求してきた場合、黙って失敗するのではなく再認証を促すプロンプトが表示されるようになった。MCP サーバー側の権限要件が増えたときに気づきやすくなる。

つまりこう使う

  • MCP サーバーのツールが急に動かなくなったら、再認証プロンプトが出ていないか確認する
  • プロンプトが出たら案内に従って再認証し、追加されたスコープを許可する
  • Claude Code Changelog
注意点

長い会話で出ていた "Prompt is too long" エラーが、自動圧縮の改善で解消（v2.1.288）

会話が長くなると "Prompt is too long" エラーで止まってしまう不具合が修正された。自動コンパクト（要約によるコンテキスト圧縮）の挙動が改善され、長時間のセッションでも継続しやすくなった。

つまりこう使う

  • 長時間セッションで同エラーに遭遇していた場合は、v2.1.288 への更新で解消しているか確認する
  • Claude Code Changelog

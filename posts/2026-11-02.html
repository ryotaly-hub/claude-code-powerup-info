新機能

`CLAUDE_CODE_DISABLE_ULTRATHINK` で `ultrathink` キーワードを無効化できるように

v2.1.316 で追加された環境変数。これまで ultrathink と入力すると、対応モデルで effort が自動的に xhigh になる仕様だったが（v2.1.311、10/31号で既報）、CLAUDE_CODE_DISABLE_ULTRATHINK を設定すると、このキーワード検知自体を無効化できる。

チームで effort・コストを一律管理したい場合に使える設定。

つまりこう使う

  • 組織やプロジェクトで effort によるコストを統制したい場合、settings.json や環境変数で CLAUDE_CODE_DISABLE_ULTRATHINK=1 を設定すると、メンバーが ultrathink と書いても自動で xhigh に上がらなくなる。

ワークフロー

auto mode でブロックされた呼び出しのメッセージに、コマンド名・再試行の可能性・`/permissions` への案内を追加

v2.1.314 で、auto mode が呼び出しをブロックしたときのメッセージが改善された。ブロックされたコマンド名を明示し、Claude が再試行して auto mode が再度チェックする可能性があることを伝え、/permissions で確認する方法も案内するようになった。

つまりこう使う

  • auto mode で作業中にブロック通知が出たら、メッセージに示されたコマンド名を確認してから /permissions を開き、許可ルールを調整するかどうか判断する。
  • Claude Code changelog (v2.1.314)
Tips

`/diff` が大規模リポジトリで軽量化、git が遅いときは再描画の間隔を自動で空けるように

v2.1.316 で /diff の挙動が改善された。大規模リポジトリでは、1回の更新につき実行するリポジトリ全体を対象にした git コマンドが通常1つ減り、git の応答が遅いときは更新の間隔を自動で空けるようになった。

つまりこう使う

  • 巨大なモノレポで /diff パネルを開きっぱなしにしていて重く感じていた場合、v2.1.316 以降に更新すれば負荷が軽くなっているはず。設定変更は不要。
  • Claude Code changelog (v2.1.316)
Tips

`/permissions` の確認タブが「Recently blocked」に改名、マークした行に対する Esc の動作をフッターに表示

v2.1.314 で /permissions のレビュータブの名称が「Recently blocked」に変わった。行をマークした状態で Esc キーが何をするかがフッターに表示されるようになり、複数行をまとめて処理するときの見通しが良くなった。

つまりこう使う

  • ブロックされた操作をまとめて見直したいときは /permissions を開き「Recently blocked」タブで対象行をマークし、フッターの案内に従って Esc で処理する。
  • Claude Code changelog (v2.1.314)
注意点

`sandbox.excludedCommands` の説明を修正。1回の呼び出し内の全コマンドが一致した場合のみサンドボックス外で実行される

v2.1.314 で sandbox.excludedCommands 設定の説明文の誤りが修正された。これまでは「リストに載っているコマンドは常にサンドボックス外で実行される」という説明だったが、実際の動作は「1回の呼び出しに含まれる全てのコマンドがリストのいずれかに一致した場合のみサンドボックス外で実行される」というもので、説明文もそれに合わせて直された。パイプや && で複数コマンドをつなぐと、1つでもリストにないコマンドが混ざっていればサンドボックス内で実行される。

つまりこう使う

  • sandbox.excludedCommands でサンドボックス外実行を許可しているコマンドがある場合、パイプや && で別のコマンドと繋ぐと丸ごとサンドボックス内に戻ることを前提に設定を見直す。
  • Claude Code changelog (v2.1.314)
エコシステム

VS Code 拡張、モデル名に `[1m]` が付いていると Effort スライダー・Ultracode スイッチ・モデル名表示が欠けていた不具合を修正

v2.1.316 で、VS Code 拡張において、設定しているモデル名に [1m] タグ（例: opus[1m]）が付いている場合、Effort スライダー・Ultracode の切り替えスイッチ・モデル名表示が出ない不具合が修正された。

つまりこう使う

  • VS Code 拡張で1Mトークンコンテキストのモデル（opus[1m] など）を指定している場合、v2.1.316 以降に更新すれば Effort スライダーや Ultracode スイッチが表示されるようになる。

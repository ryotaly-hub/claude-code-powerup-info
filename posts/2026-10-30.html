直近の更新から、CI やスキル構成で踏むと気づきにくい不具合の修正と、VS Code・WebFetch の実用的な改善をまとめた。

この号の内容

  1. 無効な名前のカスタムコマンドが1つあると、全コマンドの読み込みが止まり `claude -p` が無出力になる不具合を修正
  2. vim モードで `gj`/`gk` に大きい回数を付けた `d`/`c`/`y` が、意図せず削除・コピーしてしまう不具合を修正
  3. ディレクトリ単位のスキルが、Bash で `cd` してリポジトリの深い階層に移動した後に見つからなくなる不具合を修正
  4. Windows での git コマンドが高速化、エラー表示も git の言語設定に関係なく常に英語に
  5. クラウドセッションの WebFetch が名前解決に失敗したとき、許可すべきホスト名を名指しするように改善
  6. VS Code 拡張、Claude の返信内のコードブロックにシンタックスハイライトが追加
注意点

無効な名前のカスタムコマンドが1つあると、全コマンドの読み込みが止まり `claude -p` が無出力になる不具合を修正

v2.1.312 で、無効な名前のカスタムコマンドが1つ存在するだけで、それ以外の全てのカスタムコマンドの読み込みまで止まってしまう不具合が修正された。この不具合が起きていた環境では、原因に気づきにくいまま claude -p が何も出力せずに終了することがあった。

つまりこう使う

  • .claude/commands/ 配下にカスタムコマンドを置いて claude -p などをスクリプトから呼んでいる場合、出力が急に空になったら、まずコマンドのファイル名やフロントマターの名前に無効な文字が入っていないか確認する。
  • v2.1.312 以降ではこの事故自体は起きなくなるので、該当する不具合に心当たりがあればアップデートしておく。
  • claude-code v2.1.312 release notes
注意点

vim モードで `gj`/`gk` に大きい回数を付けた `d`/`c`/`y` が、意図せず削除・コピーしてしまう不具合を修正

v2.1.311 で、vim モードの d（削除）・c（変更）・y（コピー）を、残り行数より大きい回数の gj/gk と組み合わせたときの挙動が修正された。これまでは本来の Vim の動きと異なり削除やコピーが実行されてしまっていたが、以後は Vim と同じく、カーソル移動のみで止まるようになった。

つまりこう使う

  • vim モードで d5gj のように残り行数を超える回数を指定しても、意図せずテキストが消える事故は起きなくなる。v2.1.311 以降に更新しておけば十分。
  • claude-code v2.1.311 release notes
Tips

ディレクトリ単位のスキルが、Bash で `cd` してリポジトリの深い階層に移動した後に見つからなくなる不具合を修正

v2.1.312 で、ディレクトリ単位のスキルや frontmatter の paths: で絞ったスキルが、Bash の cd コマンドで git リポジトリの深い階層に移動した後に見つからなくなる不具合が修正された。

つまりこう使う

  • サブディレクトリごとにスキルを分けて運用している場合、作業ディレクトリを cd で移動した直後にスキルが呼ばれないと感じたら、まずは v2.1.312 以降に更新する。
  • claude-code v2.1.312 release notes
Tips

Windows での git コマンドが高速化、エラー表示も git の言語設定に関係なく常に英語に

v2.1.309 で、Claude Code が内部で実行する多数の git コマンドの速度が Windows 上で改善された。また、プラットフォームを問わず、それらの git コマンドのエラーは git 自体の言語設定にかかわらず常に英語で表示されるようになった。

つまりこう使う

  • Windows で Claude Code の動作が git 絡みで遅いと感じていた場合、v2.1.309 以降に更新すれば改善分の恩恵を受けられる。日本語化した git を使っていても、Claude Code が表示する git のエラー文自体は英語のままになる。
  • claude-code v2.1.309 release notes
ワークフロー

クラウドセッションの WebFetch が名前解決に失敗したとき、許可すべきホスト名を名指しするように改善

v2.1.312 で、クラウドセッションにおける WebFetch のエラー表示が改善された。名前解決に失敗したホストは、許可済みのネットワークドメインの外にある可能性があると説明され、Claude が許可すべきホスト名を具体的に示すようになった。

つまりこう使う

  • クラウドセッションで WebFetch が失敗したときは、エラーに示されたホスト名を確認し、必要であればそのホストをクラウド環境のネットワーク許可設定に追加する。
  • claude-code v2.1.312 release notes
新機能

VS Code 拡張、Claude の返信内のコードブロックにシンタックスハイライトが追加

v2.1.311 で、VS Code 拡張の Claude Code パネルに表示される返信内のコードブロックに、シンタックスハイライトが付くようになった。ライトテーマ・ダークテーマ・高コントラストダークテーマのいずれでも対応している。

つまりこう使う

  • VS Code 拡張を v2.1.311 以降に更新すれば自動で有効になる。設定の変更は不要。
  • claude-code v2.1.311 release notes
